# Anime Lingo — локальная студия аниме

Приложение на Electron для Windows x64 и Linux x64: добавляйте скачанные серии, смотрите с интерактивными английскими субтитрами и русским переводом, создавайте субтитры из английской озвучки и улучшайте изображение программными фильтрами на CPU.


> **Версия 0.1.0.** Windows x64 и Linux x64 из одной кодовой базы; все локальные модели работают внутри программы.
>
> **Windows: установщик не подписан.** Сертификата для подписи кода у проекта нет, поэтому при запуске `Anime Lingo-…-win-x64.exe` Windows SmartScreen покажет «Windows защитила ваш компьютер». Нажмите «Подробнее» → «Выполнить в любом случае». Сверяйте файл с `SHA256SUMS.txt` из сборки. Portable-версия (`…-portable-x64.exe`) ставится без установки и ведёт себя так же. Windows-сборка проверяется только в GitHub Actions; на реальном компьютере с Windows она пока не запускалась.
>
> **Защита улучшения видео.** На Linux обработка идёт в изоляции systemd + bubblewrap. На Windows такой изоляции нет: работает упрощённая защита (watchdog) — пониженный приоритет, контроль памяти и диска, остановка при зависании. Файлы и сеть при этом не изолируются.
>
> **ffmpeg.** На Linux берётся системный (в нём есть VAAPI/QSV), на Windows и как запасной вариант на Linux — закреплённая сборка, которую программа скачивает сама с проверкой SHA-256 (раздел «Диагностика»).

Цепочка обработки: **английский DUB → Qwen3-ASR-1.7B → выгрузка → Qwen3-ForcedAligner-0.6B → выгрузка → Hy-MT2-7B → EN + RU**. Модели работают локально. Браузер и расширение для работы приложения не нужны.

Версия **2.6.1** исправляет автоскрытие панели плеера: при воспроизведении панель времени и курсор исчезают после 2,2 секунды бездействия, включая полноэкранный режим. Движение мыши возвращает управление; на паузе, при перетаскивании ползунка и работе с клавиатуры панель остаётся доступной.

Версия **2.6** заменяет GPU-улучшение бережным режимом CPU: чёткость линий, мягкое шумоподавление, исходный размер или 2× до 4K. Обработка запускается в изоляции без GPU и сети, с лимитами 1,5 ГиБ памяти и 1,5 ядра CPU; при нехватке ресурсов или отсутствии прогресса очередь останавливается. Anime4K/Real-ESRGAN на GPU заблокированы после зафиксированного зависания Intel Xe. Нейросетевая модель для нового режима не используется. Это изменение приложения, а не исправление драйвера. Нагрузочные проверки и обработка реального видео при разработке 2.6 не запускались. Подробнее: [ENHANCEMENT-SAFETY.md](ENHANCEMENT-SAFETY.md).

Версия **2.5** добавляет папки аниме в библиотеке: «+ Папка», название, собственная локальная обложка, перенос одной или нескольких серий, поиск по папкам и сериям, порядок 1 / 2 / 10 и добавление видео прямо в открытую папку. Папки сохраняются между запусками; удаление папки возвращает серии в общий список и сохраняет субтитры и прогресс. Карточки и диалоги адаптированы до окна 1000 px.

Версия **2.4** переносит все семь экранов на оформление из предоставленных пользователем референсов: иллюстрированное боковое меню, фон у окна, синие контуры, панели просмотра, библиотека, таблица слов, история, настройки и диагностика. Создание и импорт субтитров доступны по шестерёнке в панели «Субтитры». Добавлены избранное и ручная отметка уровня слова, фильтры истории, сохранение фраз и управление окном. Диагностика читает системные сведения и наличие файлов, не запускает модели или GPU-пробы.

Версия **2.3** добавляет режим **«Короткие части»**: до шести английских слов на экране, компактный русский перевод сверху, подсветка по существующим таймкодам слов, сохранение текста в паузах и необязательная автопауза. `R` повторяет текущую часть, `T` открывает полную реплику, `A` переключает автопаузу. Настройки находятся сразу под видео и в разделе «Субтитры». Готовый перевод не переписывается и не отправляется модели повторно. Русские части внутри реплики синхронизируются приблизительно; для SRT/VTT без времён слов приблизительна также подсветка английского.

Версия 2.2 добавляет быстрый режим Anime4K с аппаратным кодированием и потоковый Real-ESRGAN: одна загрузка модели на задачу, без промежуточных PNG, автоматическая плитка и расчёт времени по недавней скорости. Способ обработки выбирается явно; результаты алгоритмов отличаются.

Версия 2.1.1 исправляет остановку `ForcedAligner word count mismatch`: текст без латинских букв пропускается как неанглийский, даже если ASR ошибочно пометил японскую песню как English. Несколько единиц ForcedAligner корректно сопоставляются одному исходному слову с сохранением настоящих интервалов. Уже начатую задачу можно запустить повторно: сохранённые результаты распознавания и выравнивания используются дальше.

## Запуск на этом компьютере

После установки: **Anime Lingo** в меню приложений или команда `anime-lingo`.

Из исходников:

```bash
cd /home/niger/Projects/anime-lingo
npm run desktop
```

1. Нажмите **«Серии и субтитры»** или перетащите видео вместе с SRT/VTT в окно.
2. Выберите английскую аудиодорожку. По умолчанию включены короткие части: английский крупнее, русский сверху. В меню под видео можно вернуть целые реплики. Для дополнительного времени включите «Автопауза»: `Space` продолжает просмотр.
3. Если подходящих субтитров нет, откройте шестерёнку справа от вкладки **«Субтитры»** и нажмите **«Создать EN + RU»**. Qwen3-ASR-1.7B распознаёт озвучку, Qwen3-ForcedAligner-0.6B определяет времена слов, Hy-MT2-7B переводит реплики.
4. Для улучшения изображения откройте **«Улучшение видео»**. По умолчанию выбран CPU и исходный размер. Доступны чёткость линий, мягкое шумоподавление и увеличение 2× до 4K.

## Возможности

- Папки по аниме с обложками PNG/JPEG/WebP до 5 МиБ, групповое перемещение серий, поиск и продолжение просмотра внутри папки.

- MP4, MKV, WebM и другие форматы, которые читает системный FFmpeg. При необходимости создаётся совместимая копия для встроенного плеера.
- Добавление серий вместе с SRT/VTT; автоматический поиск файлов с тем же именем, включая `.en` и `.ru`.
- Извлечение текстовых субтитров из MKV, включая ASS/SSA без сохранения оформления. Графические PGS/VobSub не распознаются.
- Создание английских субтитров по английскому звуку, перевод всей реплики с контекстом, подготовка заранее и обработка фрагментами во время просмотра.
- Подсветка произносимого слова по временам ForcedAligner; таймкоды сохраняются в библиотеке и работают при паузе, перемотке и изменении скорости.
- Продолжение после остановки: завершённые фрагменты распознавания/выравнивания и готовые переводы сохраняются.
- Перевод слов при наведении, произношение, локальный словарь, сохранение контекста, отметки выученных слов.
- Повтор реплики, переход между репликами, скорость воспроизведения, перемотка и полный экран.
- Экспорт SRT/VTT с выбором английского, русского или обоих языков. Словарь экспортируется в JSON.
- Бережное улучшение CPU: чёткость линий, мягкое шумоподавление, 1× / 2× до 4K, сравнение кадров и ролика по запросу, очередь серий, прогресс, оценка времени и остановка всей очереди. Доступ к видеокарте закрыт изоляцией.
- Улучшенный MKV сохраняет аудиодорожки, встроенные субтитры, вложения и метаданные, которые поддерживает FFmpeg. Подготовленные в программе субтитры сохраняются рядом в `.en.vtt` и `.ru.vtt`.
- Оригиналы не перезаписываются. Готовый результат можно добавить обратно в библиотеку.
- Модели работают последовательно и освобождаются после задач. Индикатор показывает загрузку, работу, выгрузку и состояние ожидания.

Подробности установки, использования, ограничений и устройства: [DESKTOP.md](DESKTOP.md). Данные и приватность: [PRIVACY.md](PRIVACY.md). Проверки: [TESTING.md](TESTING.md).

## Сборка и установка

Нужны Node.js 22 или новее и npm. Все локальные модели устанавливаются самой программой из раздела **«Модели»** (мастер первого запуска появится на этапе 5): Python 3.12 и PyTorch нужной сборки (CUDA для NVIDIA, XPU для Intel Arc, ROCm 7.2 для Radeon на Linux, иначе CPU), веса Qwen3-ASR и ForcedAligner, движок перевода llama.cpp (закреплён номер сборки и SHA-256) и модель Hy-MT2-7B Q4_K_M / Q6_K / Q8_0. Внешние программы, включая LM Studio, не нужны. Уже скачанный файл Hy-MT2 из LM Studio можно импортировать без повторной загрузки. Рабочее окружение Qwen на Linux (`~/.local/share/anime-lingo/qwen-env`) подхватывается без переустановки.

Данные: Linux `~/.config/anime-lingo-desktop`, компоненты `~/.local/share/anime-lingo`; Windows `%APPDATA%\anime-lingo-desktop` и `%LOCALAPPDATA%\AnimeLingo`. Папку моделей можно выбрать в разделе «Модели».

```bash
npm ci
npm run desktop:pack      # Linux: dist/desktop/linux-unpacked
npm run desktop:install   # Linux: ~/.local/opt/anime-lingo, лаунчер и ярлык
npm run desktop:appimage  # Linux AppImage
npm run desktop:pack:win  # Windows NSIS + portable (собирается в CI)
```

```bash
npm test
npm run test:electron
npm run test:desktop-live
npm run test:qwen
npm run test:enhance
npm run desktop:appimage
npm run build
```

Реальные тесты моделей требуют установленных Qwen3-ASR, Qwen3-ForcedAligner, Real-ESRGAN и Hy-MT2. Они занимают больше времени, чем модульные тесты.

`test:qwen` использует первые 35 секунд локального английского дубляжа Fate/Apocrypha. Для другого файла задайте `ANIME_LINGO_TEST_VIDEO=/путь/к/видео.mp4 npm run test:qwen`.
